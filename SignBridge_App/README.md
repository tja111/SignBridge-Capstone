# SignBridge portable application

The ready-to-share Windows application is in `dist\SignBridge`.

For researchers:

1. Extract the complete `SignBridge` folder from the ZIP.
2. Double-click `SignBridge.exe`.
3. Allow camera access if Windows asks, then select the correct camera number.

Python, the trained Alphabet and Words models, and the required assets are included.
Do not move `SignBridge.exe` out of its folder; it needs the `_internal` folder beside it.
