# Word Sign Images

Place one image per word/phrase here, named exactly as the class label.

Supported formats: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`

## Naming examples
- `Hello.png`
- `ThankYou.jpg`
- `Iloveyou.png`

The viewer will look for the image whose basename (without extension) matches the
detected class label (case-insensitive).
